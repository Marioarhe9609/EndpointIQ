🏗️ Diagrama de Arquitectura de Onyx Platform

Mapa de componentes de infraestructura, base de datos analítica, servidor de ingesta e inteligencia artificial.

💻

1. Agente Endpoint (Windows)

  • Servicio Windows: OnyxMonitor
  • Ingesta: onyx_agent.py cada 60s
  • Sensor GPS: PowerShell GeoCoordinateWatcher
  • Telemetría: CPU, RAM, Disco, Procesos PID
☁️

2. Cloud Run Server

  • Servidor Web: Python server.py
  • Cifrado: HTTPS TLS 1.3
  • Sesión: Cookies HttpOnly; Secure
  • Auth Híbrido: Active Directory LDAP
🗄️

3. Base de Datos BigQuery

  • Dataset: onyx (us-central1)
  • eq_sync_status — Estado Flota
  • eq_hardware_metrics — Telemetría & GPS
  • eq_device_inventory — Registro Activos
  • eq_device_assignments — Custodia
🤖

4. Vertex AI & Frontend

  • IA Engine: Google Vertex AI
  • Soporte: Bot de WhatsApp
  • Frontend: Single Page App (Vanilla JS)
  • Mapas: Leaflet.js GPS real
