Opciones de Implementación
Tres enfoques posibles con sus pros y contras
📱
App Nativa
Kotlin (Android) + Swift (iOS)
  • Acceso total a APIs del sistema
  • Mejor performance en background
  • GPS preciso (~5 metros)
  • Foreground Service continuo
  • Dos codebases separados
  • Mayor tiempo de desarrollo
🔄
Cross-Platform
Flutter / React Native
  • Un solo código para ambas plataformas
  • Desarrollo más rápido
  • Menor costo mantenimiento
  • Menos acceso a APIs nativas
  • Performance inferior en background
  • No recomendado para servicios 24/7
🏢
MDM Enterprise
Intune / Google Endpoint / Jamf
  • Acceso total al dispositivo
  • Funciona en Android + iOS
  • Políticas de seguridad empresariales
  • Costo $3-12 USD/mes por dispositivo
  • Curva de aprendizaje alta
  • Menos personalizable
🍎
iOS es muy restrictivo. Apple no permite que apps de terceros accedan a CPU, RAM, procesos activos, ni historial de navegación. Para monitoreo empresarial en iOS se requiere un perfil MDM (Mobile Device Management).
🏆
Recomendación: Enfoque Híbrido
Empezar con Android nativo → Expandir con MDM → iOS
💡
Empezar con Android nativo (mayor cuota de mercado empresarial, más permisos disponibles) y luego expandir a iOS con MDM. El servidor actual NO necesita cambios — el endpoint /api/agent-ingest ya acepta los datos que enviaría una app móvil.

Fases de Implementación
Roadmap completo con tareas detalladas
Fase 1 — 2-3 Semanas
📱 App Android Nativa (Kotlin)
Desarrollo de la app base con todas las métricas core y servicio en segundo plano.
  • Crear proyecto Android (Kotlin, minSDK 26 / Android 8.0+)
  • MetricsCollector — CPU, RAM, Disco, Batería
  • LocationTracker — GPS con FusedLocationProvider (~5m precisión)
  • AppUsageTracker — UsageStatsManager (apps más usadas)
  • NetworkMonitor — WiFi, VPN, señal celular, tipo de red
  • HttpSender — POST a /api/agent-ingest (mismo formato que Windows)
  • OfflineBuffer — SQLite (Room) para datos sin conexión
  • Foreground Service para ejecución continua 24/7
  • Auto-start al encender el dispositivo
  • Setup por código QR (escanear para configurar servidor)
  • UI mínima: estado del agente, último envío, toggle on/off
  • Testing en 3+ dispositivos Android
Fase 2 — 3-4 Semanas
🏢 Android Enterprise / MDM
Integración empresarial para despliegue masivo y control de políticas.
  • Device Admin para políticas empresariales
  • Managed Configurations para despliegue masivo
  • Zero-touch enrollment (configuración automática)
  • Integración con Google Endpoint Management
  • Restricciones: bloquear desinstalación, forzar GPS activo
  • Distribución via Google Play Managed (sin Play Store público)
  • Kiosk mode para tablets de uso fijo (opcional)
Fase 3 — 4-6 Semanas
🍎 Soporte iOS (con MDM)
App iOS complementaria con perfil MDM para métricas que Apple restringe.
  • Crear proyecto Xcode (Swift, iOS 16+)
  • Implementar métricas permitidas (batería, red, GPS)
  • Background App Refresh handler (mínimo 15 min)
  • Integración con Apple MDM (Apple Business Manager)
  • Perfil MDM para Screen Time y restricciones
  • Distribución via Apple Business Manager
  • Cuenta Apple Developer Enterprise ($99/año)
Fase 4 — 1 Semana
📊 Dashboard — Filtros Móviles
Agregar filtros y vistas para dispositivos móviles en el dashboard.
  • Filtro por tipo: Desktop | Celulares | Tablets
  • KPIs específicos: batería, señal, screen time
  • Mapa: iconos diferentes para móvil vs desktop
  • Vista "Apps más usadas" (reemplaza Top Procesos)

Decisiones Pendientes
Necesitamos definir estos puntos antes de iniciar
1
¿Qué dispositivos? — ¿Solo Android? ¿También iOS? ¿Tablets específicas?
2
¿Cuántos dispositivos? — Esto afecta si necesitamos MDM o solo APK directo
3
¿Play Store o APK directo? — Play Store requiere revisión de Google; APK es inmediato
4
¿Qué métricas son prioritarias? — GPS, apps usadas, batería, ¿todas?
5
¿Monitoreo de llamadas/SMS? — Requiere permisos sensibles y aprobación especial de Google
6
¿Kiosk mode para tablets? — ¿Las tablets son de uso fijo (ej: recepción, bodega)?
7
¿Tienen Google Workspace? — Simplifica MDM con Google Endpoint Management
8
¿Presupuesto para Apple Developer? — $99/año necesario para distribuir en iOS
