1. Arquitectura General del Sistema

Onyx opera bajo una arquitectura de microservicios contenerizada en Google Cloud Run con base de datos analítica en Google BigQuery e integración con Google Vertex AI.

[Endpoint Windows Agent] ➔ (HTTPS 443 TLS 1.3) ➔ [Cloud Run server.py] ➔ [(BigQuery Dataset: onyx)]

2. Diccionario de Datos (BigQuery)

CampoTipoDescripción

3. Catálogo de APIs REST (Backend)

MétodoEndpointDescripción
POST/api/auth/loginAutenticación híbrida AD/Local y emisión de cookie onyx_session.
GET/api/devicesTelemetría consolidada de la flota para el Dashboard General.
GET/api/security-dashboardMapa con coordenadas GPS reales de Windows y eventos pasivos.
POST/api/inventoryRegistro de equipos con fechas de almacén, asignación y agente.
PUT/api/inventory/updateActualización y autodetección de re-asignaciones entre funcionarios.
POST/api/agent/ingestIngesta de telemetría HTTPS transmitida por los agentes locales.

4. Especificaciones del Agente de Endpoint

El agente onyx_agent.py se ejecuta como Servicio de Windows (OnyxMonitor). Extrae coordenadas GPS reales de Windows mediante PowerShell System.Device.Location.GeoCoordinateWatcher y transmite métricas cada 60 segundos.
